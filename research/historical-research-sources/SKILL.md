# 历史史料线上获取途径（全朝代）

## 二、学术数据库项目（免费）

### 1. CBDB（中国历代人物传记资料库）
- **网址**: projects.iq.harvard.edu/cbdb
- **内容**: 42万+人物传记数据，涵盖先秦至清
- **访问**: 免费，支持API查询
- **查询**: 可按姓名、籍贯、科年、官职检索

### 2. CTEXT（中国哲学书电子化计划）
- **网址**: ctext.org
- **内容**: 先秦至清经典文献，含注疏
- **访问**: 免费，支持全文检索

### 3. 殆知阁古代文化数据库
- **网址**: daizhige.org
- **内容**: 经史子集全文检索
- **访问**: 免费

### 4. 汉籍电子文献
- **网址**: hanchi.ihp.sinica.edu.tw
- **内容**: 台湾中央研究院，二十五史、十三经等
- **访问**: 免费

## 九、搜索策略模板

### 历史人物研究流程
1. **确定基本信息**：姓名、字号、籍贯、朝代
2. **CBDB查询**：获取科年、仕途、家族
3. **地方志检索**：籍贯地府县志
4. **碑传集检索**：传记资料
5. **清实录/明实录**：任官记录
6. **朱卷/科举录**：科举详细信息

### 历史事件研究流程
1. **正史检索**：二十四史相关纪传
2. **实录检索**：编年记录
3. **方志检索**：地方视角
4. **笔记野史**：补充细节

## 十、注意事项

1. **数据验证**：多源交叉验证，单一来源不可靠
2. **版本问题**：古籍有不同版本，注意校勘
3. **访问限制**：部分数据库需机构权限
4. **数字化程度**：各朝代数字化程度不同，明清最完善
5. **姓名异体**：古人姓名有多种写法，需全面检索

## 十二、使用 Skill 的标准流程

### 1. 确定研究目标
- 人物研究 → CBDB + 地方志 + 碑传
- 事件研究 → 正史 + 实录 + 笔记
- 家族研究 → 族谱 + 朱卷 + 地方志
- 地理研究 → CHGIS + 地方志 + 古地图

### 2. 多源交叉验证
- 至少 3 个独立来源验证同一信息
- 注意版本差异和校勘问题
- 记录所有来源以便引用

### 3. 数据整理与输出
- 结构化存储（JSON/CSV）
- 生成研究报告
- 保存为 Skill 以便复用

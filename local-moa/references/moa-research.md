# MoA 多模型委员会研究笔记

## 核心论文谱系

### 1. 开山之作：MoA (Together AI, 2024)
- arxiv:2406.04692
- 多层架构：proposers → aggregator → 反复迭代
- AlpacaEval 2.0 达到 65.1%，碾压 GPT-4 Omni (57.5%)
- GitHub 2955 star，持续维护

### 2. 独立验证：Wisdom of the Silicon Crowd (2024)
- Schoengger et al., 宾大 Tetlock 团队
- 12 LLM 集成预测 vs 925 人类，31 个二元问题
- 结论：LLM 群体与人类群体无显著差异

### 3. RouteMoA (ACL 2026)
- 轻量评分器预筛选模型，只调用高潜力子集
- 成本降低 89.8%，延迟降低 63.6%

### 4. Beyond Consensus (2026)
- 关键发现：单模型温度扰动 > 异构模型池
- 原因：推理路径多样性 > 模型多样性（训练数据差异）
- 不同模型的知识冲突可能成为噪音

### 5. ModelSwitch (2025)
- arxiv:2504.00762
- 多模型 × 重复采样 × 一致性信号切换
- 在 MMLU-Pro 上同时碾压纯 Self-Consistency 和纯多模型辩论

### 6. ReM-MoA (2026)
- 证明深度扩展会出现退化、早停、饱和
- 层数多了反而更差，需要推理记忆机制

### 7. MCA (2026)
- 核心：选互补性最强的组合，不是选最强的模型
- 用 greedy 特征选择评估模型间互补性

## 关键洞察

### 推理路径多样性 vs 模型多样性
- 模型多样性来自训练数据差异 → 同一个问题在不同知识库上搜索
- 推理路径多样性来自 temperature 扰动 → 同一个知识库用不同方式思考
- 在推理密集型任务上后者更有效
- 但在知识盲区场景（模型训练数据缺失某知识点），跨模型多样性不可替代

### 开放式推理 vs 封闭式基准
- 论文所有数字都来自 MMLU/MATH/AlpacaEval（封闭式）
- 开放式任务（代码调试、策略分析）的增益机制不同：
  - 天花板更高：从"定位一层"到"定位三层"可能是 200% 提升
  - 但没有标准答案，聚合器可能引入噪音
- 结论：论文数字是下限，实际开放式任务增益区间很大

### 成本收益分析
- MoA 提升 10-15%（封闭式基准），成本 5-15x
- 对日常任务性价比极低
- 适用场景：
  1. 单模型卡死（多轮问不出答案）
  2. 关键决策（策略回测、安全审查）
  3. 验证（单模型结论过于自信但直觉不对劲）

## 互补性评估框架

判断两个模型是否互补，四个维度：

1. **错误模式正交性**：A 错 B 对，B 错 A 对？还是同时错？
2. **推理路径多样性**：分析路径不同还是殊途同归？
3. **知识覆盖差异**：训练数据覆盖不同领域？
4. **聚合亲和力**：输出格式、详细程度是否兼容？

打分规则（每个问题 0-2 分）：
- 几乎一样：0 分
- 各有侧重但结论一致：0.5 分
- 推理路径完全不同：1.5 分
- A 对 B 错且互斥：2 分

总分/题目数 > 1.0 值得用，> 1.5 效果显著。

## MiMo + DeepSeek 互补性分析

- MiMo：小米训练，偏消费电子/IoT/中文互联网
- DeepSeek：偏学术/代码/结构化推理
- LVGL 场景：MiMo 懂硬件约束直觉，DeepSeek 擅代码严密推理
- 策略回测：MiMo 实用角度，DeepSeek 数学/统计角度
- 预判：中高度互补

## 当前实现决策

- 采用 ModelSwitch 方案（跨模型）而非 Beyond Consensus（纯同模型温度扰动）
- 原因：开放式任务的瓶颈是知识盲区，不是推理路径单一
- 架构：MiMo ×1 + DeepSeek提案 ×1 = 2 提案者，DeepSeek 聚合
- 成本：3 次 API 调用（vs 单模型 1 次）
- 未实现迭代轮次（1 轮提案 + 1 次聚合），2 轮迭代是性价比最优的安全区间

# Model Complementarity Analysis for MoA

## Methodology: CORE 论文四象限矩阵

基于 Mishra et al. (2026) 提出的 DPP 方法，简化版：

1. 准备 15-20 道实际高频问题（3 场景 × 5-7 题）
2. 每个模型独立作答
3. 用 DeepSeek 做匿名裁判（不告诉它哪个答案是自己），三维度评分：
   - 逻辑完整性
   - 事实准确性
   - 覆盖深度
4. 填入四象限矩阵：

| | 模型B 好 | 模型B 差 |
|---|---|---|
| 模型A 好 | 双好 | A 独好 |
| 模型A 差 | B 独好 | 双差 |

5. 互补性 = (A独好 + B独好) / 总题数

判决标准：
- >20%：强互补，MoA 物有所值
- 5-20%：弱互补
- <5%：冗余

## 关键论文发现

### Beyond Consensus (Fadnavis et al., 2026.05)
- 单模型温度扰动（推理路径多样性）在封闭式基准上可超过异构模型池
- 但在开放式任务中，跨模型多样性（知识盲区覆盖）更关键
- 因为开放式任务的最大瓶颈是「这个知识点模型有没有」，不是「推理够不够多角度」

### ModelSwitch (2025.04)
- 多模型 × 重复采样 × 一致性信号切换
- 同时碾压纯 Self-Consistency 和纯多模型辩论
- 提升幅度：事实准确性 +10-15%，盲区覆盖 +15-25%

### MCA (2026.05)
- 选互补性最强的组合，不是选最强的模型
- Greedy 特征选择：每轮加入最大化与已有集合互补性的模型

## 脚本工具
